
Talk thumbnails are stored in `img/talks/` and referenced by the optional
`thumbnail` field in `data/talks.yaml`. Use local image paths rather than external
URLs. Thumbnails appear beside talk descriptions on screen and in print; talks
without a thumbnail remain text-only.
